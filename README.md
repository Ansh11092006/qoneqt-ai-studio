# Qoneqt AI Studio

Qoneqt AI Studio is an AI-powered video creation platform designed to turn an idea or prompt into a structured, publish-ready video workflow.

## 🚀 Features

- AI-powered video generation workflow
- Prompt-based content creation
- Modern interactive web interface
- AI-assisted script and content generation
- Media processing pipeline
- FastAPI backend
- React-based frontend
- Local development support

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- GSAP
- Three.js

### Backend
- Python
- FastAPI
- Uvicorn
